  Primary Request and Intent

  - 对 onset - 50 ms

  - 将 PURE_WIND_PREPEND_FRAMES=570 改为基于 dt_ms 的配置项，避免 magic number

  2. 修复二维运动学

  重点文件：

  - scripts/prepare_data.py
  - nsmor/pipeline/kinematics.py
  - nsmor/pipeline/io.py
  - scripts/pre_load_adapt.py

  当前 np.gradient(sqrt(x²+y²)) 是径向速度，不是路径速度。应改为：

  vx = np.gradient(x_smooth, dt_s)
  vy = np.gradient(y_smooth, dt_s)
  velocity = np.sqrt(vx**2 + vy**2)

  加速度必须使用真实时间间隔：

  acceleration = np.gradient(velocity, timestamp_s)

  或使用逐步差分并显式除以 dt_s。

  同时：

  - 检查 timestamp 严格递增；
  - 对零间隔、负间隔和掉帧制定明确策略；
  - 保留物理单位；
  - 边界导数使用明确的一侧差分或标记规则；
  - scripts/pre_load_adapt.py 中的同类 diff() 逻辑同步修复；
  - 对 heading 先 unwrap，再进行反射，避免 % 360 制造人为跳变。

  回归测试：

  - 圆周切向运动的速度应为正，而不是接近零；
  - 匀加速轨迹的加速度应恢复正确物理单位；
  - 10 ms 和 20 ms 采样间隔下，结果不能因漏除 dt 而改变约 100 倍；
  - timestamp 异常必须被拒绝或显式记录。

  P2：修复 publication statistics 和评估逻辑

  1. Integration statistics 完整化

  重点文件：

  - scripts/analyze_integration.py
  - nsmor/analysis/uq.py

  每个预先声明的比较至少输出：

  estimand
  unit_of_analysis
  n_sessions
  n_trials
  mean_difference
  effect_size
  effect_size_definition
  confidence_interval
  raw_p_value
  adjusted_p_value
  correction_method
  comparison_family
  missingness

  推荐默认设计：

  - session 作为独立 resampling unit；
  - 同一 session 的条件比较使用 paired contrast；
  - 先在 session 内聚合，再进行 paired permutation 或 Wilcoxon；
  - trial-level bootstrap 不能被当成独立 session 证据；
  - 每个 figure/table 定义自己的 multiple-comparison family；
  - 使用 Holm-Bonferroni；若 publication protocol 明确要求 FDR，再实现并接入
    Benjamini–Hochberg；
  - 不能只计算 p 值而不定义比较集合。

  效应量应区分：

  - paired contrast：d_z 或明确的 paired Cohen’s d；
  - independent groups：pooled-SD Cohen’s d；
  - bootstrap CI：明确 percentile 或 BCa 方法。

  2. 正确处理零方差效应量

  nsmor/analysis/uq.py 中不能把非零均值差且两组方差为零静默报告为 d=0。

  建议输出：

  effect_size: null
  effect_size_status: "degenerate_nonzero_difference"
  effect_size_direction: "positive" | "negative"

  或者在内部使用带符号的无穷大，但最终 JSON/CSV 必须避免不可移植的非有限浮点值。

  对于：

  - 两组均为相同常数：效应量为 0；
  - 两组为不同常数：报告确定性差异和 degenerate 状态；
  - 仅一组零方差：按预先声明的 pooled-SD 规则处理并给出 warning。

  3. 删除错误的 OOF/ensemble KS fatal gate

  重点文件：

  - scripts/prepare_data.py

  OOF 单 fold 预测和部署时 ensemble 平均预测具有不同方差结构。ensemble
  方差变小是预期现象，不能用同一 snapshots 上的独立样本 ks_2samp 作为 fatal
  gate。

  改为报告性诊断：

  - paired mean absolute discrepancy；
  - paired RMSE；
  - classwise probability discrepancy；
  - row-sum、finite-value 和 non-negative 检查；
  - calibration、Brier score 或 log loss；
  - decision-equivalence rate；
  - 在真正独立的 grouped holdout 上评估 ensemble 性能；
  - 若设置阈值，只对有限性、概率归一化、类别覆盖和明确的 decision-equivalence
    tolerance 使用 hard gate。

  OOF 仍然必须保留，用于避免 same-sample label leakage；只是不能要求 OOF 与
  ensemble 数值分布完全相同。

  4. Lesion 和 psychophysics 使用合适的 resampling

  重点文件：

  - scripts/simulate_lesion.py
  - scripts/simulate_psychophysics.py

  Lesion：

  - 优先按 session bootstrap；
  - trial 配对时使用 paired permutation 或 Wilcoxon；
  - 不对 class-filtered、非连续 trial 伪造 block_size=5 circular bootstrap；
  - MSE 等右偏指标至少提供稳健性分析；
  - 输出 effect size、CI 和 adjusted p-value。

  Psychophysics：

  - visual angle 噪声必须保持在 [0, 180]；
  - 优先使用 truncated Gaussian 或明确的反射边界策略，而不是无界 Gaussian
    后静默接受负角度；
  - 报告实际噪声分布和边界命中率；
  - validation trial 通过 provenance key 映射，不按 raw event 尾部 20% 推断；
  - 明确该分析是 visual-channel noise sensitivity，不要称为完整 Bayesian
    cue-combination 验证。

  - nsmor/analysis/dynamics.py
  - scripts/analyze_jacobian.py

  修改方案：

  Hard Acceptance Gates

  Gate A：执行

  - synthetic raw data 可由单条 runner 命令完成 ETL、训练和全部分析；
  - 任一阶段失败都会返回非零；
  - 所有产物位于唯一 run 目录；
  - gating analysis 实际运行。

  Gate B：数据完整性

  - trial key 唯一且全链路一致；
  - 无位置 join；
  - onset、TTC、condition 和 label 可追溯；
  - drop log 完整；
  - timestamp、velocity、acceleration 单位和时间语义通过 synthetic tests。

  Gate C：无泄漏

  - train/validation/test session 不重叠；
  - normalization 只来自 training sessions；
  - OOF prior 不使用 held-out label 或 held-out session；
  - evaluation 不含随机 crop；
  - online 输入不使用未来帧；若仅用于离线标签，必须明确标注。

  Gate D：统计

  - 每个正式比较均有 effect size、CI、raw p 和 adjusted p；
  - comparison family、resampling unit、missingness 有记录；
  - 零方差情况不再静默变为零效应；
  - 统计输出全部可序列化且无 NaN/Inf。

  Gate E：可复现性

  - 同一 seed、同一环境和同一输入可重建相同 split、manifest 和规定容差内的结果；
  - checkpoint 中断恢复通过；
  - 多 seed 结果有汇总，不只报告最佳 seed；
  - CI 和 Docker clean build 通过。

         +]:                                                             
      49 +    """                                                        
      50 +    Extract ``(all_options, required_options)`` from a script's
         + AST.                                                          
      51 +

      59 +    for node in ast.walk(tree):                                
      60 +        if not isinstance(node, ast.Call):

      63 +        if not (isinstance(func, ast.Attribute) and func.attr =
