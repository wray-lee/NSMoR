## 写入原则

只记**下次会再踩**的东西：

- ✅ 静默出错的陷阱（测试假通过、数值污染）
- ✅ 违反直觉的性能实测（"加速方案"反而更慢）
- ✅ 环境/工具链坑（文件系统、混合精度、跨框架数值差异）
- ❌ 已经被代码或 git history 记录的（改了什么、修了哪个 bug）
- ❌ 一次性的操作细节

每条包含：**现象 → 根因 → 怎么避免**。命名 `YYYY-MM-DD-slug.md`。
