# NSMoR

Dual-pathway recurrent neural network modeling cricket multi-sensory integration, combining spiking and continuous dynamics under a learned routing gate.

## Language

### Architecture

**NSMoRCore**:
The top-level neural network module composing a FrontendEncoder and a BioDecisionCore, accepting an 8-dimensional padded feature tensor and producing per-timestep scalar velocity predictions.
_Avoid_: model, network, MoR

**LIF Pathway**:
Leaky Integrate-and-Fire spiking neuron pathway for fast, event-driven sensory transient processing. Implements synaptic delay, refractory periods, spike-frequency adaptation, short-term plasticity, and lateral inhibition.
_Avoid_: Path A, spiking path

**GRU Pathway**:
Gated Recurrent Unit pathway for smooth, continuous temporal integration of sensory signals.
_Avoid_: Path B, continuous path

**MoR Router**:
Per-timestep routing network that produces independent softmax weights blending LIF Pathway and GRU Pathway outputs, conditioned on sensory encoding and MCMC Prior.
_Avoid_: gate, mixer, blender

**FrontendEncoder**:
Stage 1 of the Hybrid Funnel architecture, encapsulating optional dendritic compartmentalization (IIR filtering on visual channels) and the SensoryEncoder, mapping raw 4-D sensory features to hidden representations.
_Avoid_: encoder, frontend, stage 1

**BioDecisionCore**:
Stage 2 of the Hybrid Funnel architecture, containing the dual-pathway recurrent network (LIF + GRU), the MoR Router, pathway integration, and the DirectionHead decoder.
_Avoid_: backend, decision core, stage 2

**SensoryEncoder**:
A feedforward module mapping 4-D raw sensory features to hidden representations with optional Gaussian noise injection for stochastic resonance.
_Avoid_: input encoder, feature encoder

**DirectionHead**:
The final decoder module that maps integrated hidden representations to scalar velocity predictions.
_Avoid_: decoder, output head, prediction head

**Hybrid Funnel**:
Two-stage architecture separating sensory encoding (FrontendEncoder) from bio-decision (BioDecisionCore), supporting two-phase training with gradient isolation via requires_grad toggling.
_Avoid_: funnel, two-stage model

### Biophysics

**Surrogate Gradient**:
Straight-through estimator enabling backpropagation through the non-differentiable spike operation: forward pass produces binary spikes, backward pass flows gradients through a sharpened sigmoid forced to FP32.
_Avoid_: STE, straight-through

**Short-Term Plasticity (STP)**:
Tsodyks-Markram synaptic dynamics modulating LIF input current via paired facilitation and depression state variables.
_Avoid_: synaptic plasticity, TM model

**Truncated BPTT**:
Gradient truncation strategy that detaches LIF recurrent state every N timesteps to bound gradient path length and prevent memory explosion in long sequences.
_Avoid_: TBPTT, gradient truncation

### Data & Provenance

**MCMC Prior**:
A 4-dimensional probability vector [P(ESCAPE), P(PREWALK), P(PRE_ACTIVE), P(NO_RESPONSE)] generated by cross-fitted logistic regression from a 5-D Snapshot, broadcast identically across all frames of a trial.
_Avoid_: prior, probability vector

**Snapshot**:
A 5-dimensional feature vector extracted 50 ms before a trial's anchor instant: visual_angle, looming_velocity, wind_state, avg_velocity_bg, max_acceleration_bg. Used as input to the MCMC Prior generator. The anchor is condition-dependent — wind onset for any trial carrying wind, the looming collision for visual-only trials, whose looming begins at trial start. Each trial records which anchor rule produced it.
_Avoid_: feature vector, TTC snapshot

**Cross-Fitted OOF Priors**:
Out-of-fold MCMC prior probabilities generated via K-fold cross-fitting with session-grouped stratification, ensuring each trial's prior is produced by a model that never saw that trial's label or any trial from its recording session.
_Avoid_: OOF, out-of-fold priors

**Ensemble Priors**:
Fold-ensemble MCMC posteriors averaged across all K fold models, with lower variance than OOF Priors by construction. Used at inference time.
_Avoid_: served priors, deployment priors

**Pipeline Semantics Version**:
A provenance stamp embedded in every checkpoint and dataset artifact, enforcing that loaders reject artifacts produced under incompatible scientific semantics. Current version: 2.2.
_Avoid_: version, stamp, tag

**Trial-Start Anchor**:
The temporal reference point for all continuous sequences, defined as the moment of the 2-second absolute static baseline onset. Sequences are extracted from this anchor forward.
_Avoid_: baseline onset, sequence origin

**Pure-Wind Trial**:
An experimental trial with no visual looming stimulus, receiving 570 frames of zero-padding prepended to align temporally with looming trials.
_Avoid_: wind-only trial

**Session-Grouped Split**:
Train/val partition that assigns entire recording sessions to one side, preventing within-session information leakage from shared animal baseline and gain state.
_Avoid_: session split, grouped split

### Behavioral Classification

**Escape**:
Behavioral label for trials where post-stimulus sustained speed exceeds 50 mm/s for 250ms and pre-stimulus speed was below 10 mm/s, indicating a stimulus-locked giant-fiber-mediated wind escape response.
_Avoid_: startle, flight response

**Prewalk**:
Behavioral label for trials showing both post-stimulus escape AND pre-stimulus locomotion above 10 mm/s for at least 50% of the last 1 second before stimulus onset.
_Avoid_: walking, pre-stimulus locomotion

**Pre_Active**:
Behavioral label for non-responding trials where the animal exhibited spontaneous baseline activity above a low velocity threshold.
_Avoid_: active baseline, spontaneous

**No_Response**:
Behavioral label for trials where post-stimulus sustained speed did not exceed 50 mm/s for 250ms.
_Avoid_: non-responder, inactive

### Training

**BioJointLoss**:
Composite loss function combining masked MSE, router regularization (penalizing GRU gate collapse), ATP metabolic energy cost, population sparsity L1 penalty, and temporal coherence (jerk) penalty.
_Avoid_: loss, joint loss, bio loss

**Hybrid Funnel Training**:
Two-phase training strategy where Phase 1 trains FrontendEncoder with plain MSE loss and Phase 2 trains BioDecisionCore with physics/ATP/sparsity penalties.
_Avoid_: two-phase training, funnel training

**Warmup Factor**:
Epoch-dependent scalar that ramps bio-regularization loss terms from zero to full strength over a configurable number of epochs. Does not affect the primary MSE term.
_Avoid_: annealing, ramp

**Atomic Checkpoint**:
Write-to-tmp-file + fsync + os.replace pattern that prevents a crash during torch.save from producing a truncated checkpoint at the target path.
_Avoid_: safe save, checkpoint wrapper

### Analysis

**Gating Fingerprint**:
A 16-dimensional vector summarizing a trial's MoR routing strategy without time windows, used for unsupervised clustering of routing dynamics.
_Avoid_: fingerprint, routing feature

**FixedPointAdapter**:
An analysis adapter that extracts un-padded GRU hidden-state trajectories and computes Jacobian matrices for dynamical systems fixed-point and stability analysis.
_Avoid_: dynamics adapter, Jacobian tool

**Path Speed**:
2-D Cartesian speed sqrt(dx/dt^2 + dy/dt^2), measuring actual distance traveled per unit time. The correct kinematic quantity for cricket 2-D paths.
_Avoid_: tangential speed, radial speed, velocity magnitude

**Argmax Agreement**:
Fraction of trials where OOF Priors and Ensemble Priors nominate the same most-likely behavioral class. Descriptive only, never a gate: the MoR Router consumes the prior vector rather than its argmax, and a prior generator collapsed onto the majority class scores perfect agreement. Train-serve consistency is reported as total-variation distance on the prior vector instead.
_Avoid_: prior agreement, class agreement
